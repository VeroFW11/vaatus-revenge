## Things to decide

- [ ] **What does each stat do?** Fill in the table below.
- [ ] **What powers bending?** Elden Ring has a separate "Mind" stat that powers spells (FP). Does bending use stamina, its own chi bar, or the Bending stat?
- [ ] **Does Bending cover all four elements, or does each element scale differently?** (e.g. Earth scales with Strength, Air with Dexterity.)
- [ ] **What is Intelligence for?** Spirit abilities? Energybending? Status effects? Reading ancient texts?
- [ ] **Skill tree shape.** One tree per element, plus an Avatar State tree? How do you earn skill points: by levelling, from masters, or from artifacts?
- [ ] **Are sub-bending skills unlockable?** Lightning, combustion, lava, sand, seismic sense, plant, healing, flight. (Metal and blood are ruled out by the era; see the lore check below.)

## Claude's suggestions

**Stat table (first draft, change freely):**

| Stat | Raises | Scales |
|---|---|---|
| Vigor | Max health | Survival |
| Stamina | Stamina bar (dodge, block, attack) and equip load | Heavier armour |
| Strength | Heavy weapon damage | Earth, heavy strikes |
| Dexterity | Fast weapon damage, attack speed | Air, Fire |
| Intelligence | Spirit abilities, status effect power | Water, spirit skills |
| Bending | Bending damage and chi pool | All elements |

**Skill tree layout:**

```
Fire tree          Air tree           Water tree         Earth tree
 ├ Basics           ├ Basics           ├ Basics           ├ Basics
 ├ Techniques       ├ Techniques       ├ Techniques       ├ Techniques
 └ Sub-bending:     └ Sub-bending:     └ Sub-bending:     └ Sub-bending:
   Lightning,         Flight,            Healing,           Lava,
   Combustion         Spiritual          Plant              Sand, Seismic

                 Avatar State tree
         (unlocked in story stages, see 02 Storyline)
```

**Lore check on sub-bending in our ancient era:**
- **Metalbending:** Toph invented it in Aang's era, so it **can't exist** yet.
- **Bloodbending:** Hama developed it in Aang's era, so it's safest left out, or kept as a forbidden rumour.
- **Energybending:** safe. The lion turtles and Wan used it.
- **Flight:** safe. Guru Laghima flew thousands of years before Aang.
- **Lightning, lava, combustion:** canon never gives an origin, so they can be treated as rare, ancient arts.

**Design tip:** start with fewer stats than you think you need. Every stat has to change how the game plays, or players will ignore it.
