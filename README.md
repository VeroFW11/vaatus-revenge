# The Missing Bison

An Avatar: The Last Airbender–inspired action RPG with a souls-like (Elden Ring) gameplay loop.

You wake as the Avatar in a world torn between the Spirit World and the physical world. Learn all four elements, unlock the Avatar State piece by piece, and defeat Vaatu.

> Status: **Concept / pre-production.** No playable build yet.

## Repo layout

| Folder | What goes in it |
|---|---|
| `docs/` | Design docs: vision, gameplay, world, story, characters, art direction, asset list |
| `docs/knowledge/` | Curated reading list and summaries we (and Claude) reference during the build |
| `art/` | Source art: Blender `.blend` files, concept art, textures, reference images |
| `game/` | The Unity project (created once the engine version is locked in) |

## First-time setup (both of us)

1. Install [Git for Windows](https://git-scm.com/download/win) (includes Git LFS).
2. Run once: `git lfs install`
3. Clone the repo: `git clone <repo-url>`
4. Install [Blender](https://www.blender.org/download/) (free).
5. Install Unity Hub + the Unity version listed below (once chosen).
